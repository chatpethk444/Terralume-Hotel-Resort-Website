## 1. Design System & Tokens (Ref: Brand Direction Board)

### 1.1 Color Palette

คุมโทนด้วยชุดสี **Earthy tones inspired by nature** สร้างบรรยากาศที่อบอุ่น เงียบสงบ และหรูหรา

| Role                 | Color Name                          | Hex Code                        | Reference on Board           | Description                                         |
| :------------------- | :---------------------------------- | :------------------------------ | :--------------------------- | :-------------------------------------------------- |
| **Primary Base**     | Sand                                | `#E5C89F`                       | `COLOR PALETTE` (วงกลมที่ 1) | สีทรายนวล ใช้เป็นพื้นหลังรอง หรือ Accent นุ่มนวล    |
| **Secondary Accent** | Terracotta                          | `#C37956`                       | `COLOR PALETTE` (วงกลมที่ 2) | สีดินเผา ใช้สำหรับเน้นส่วนข้อความสำคัญ ปุ่ม Hover   |
| **Accent Glow**      | Olive Gold                          | `#BE9244`                       | `COLOR PALETTE` (วงกลมที่ 3) | สีทองโอลีฟ ใช้ตกแต่งรายละเอียด สัญลักษณ์พิเศษ       |
| **Neutral / Text**   | Deep Brown                          | `#654433`                       | `COLOR PALETTE` (วงกลมที่ 4) | สีน้ำตาลเข้ม ใช้สำหรับตัวหนังสือหลักและปุ่ม Primary |
| **Sub-Neutrals**     | Sage Gray / Dark Stone / Warm White | `#7A847C`, `#3C3835`, `#F6F4EE` | วงกลมขนาดเล็กด้านล่าง        | ใช้เป็นสีพื้นหลังหลัก (Warm White) และขอบการ์ด      |

### 1.2 Typography Hierarchy

| Level                     | Font Family                | Weight                      | Size (Desktop/Mobile)                 | Reference on Board                              |
| :------------------------ | :------------------------- | :-------------------------- | :------------------------------------ | :---------------------------------------------- |
| **Hero Display**          | `Playfair Display` (Serif) | Regular / SemiBold          | 56px / 36px                           | Ref: "Nature's Beauty, Your Perfect Stay"       |
| **Section Headings (H2)** | `Playfair Display` (Serif) | Regular                     | 36px / 28px                           | Ref: "Deluxe Sea View Room", "More Than a Stay" |
| **Eyebrow / Subhead**     | `Montserrat` (Sans-serif)  | Medium (Uppercase, Spacing) | 12px / 10px (Letter-spacing: +0.2em)  | Ref: "A PLACE TO SLOW DOWN", "EXPERIENCES"      |
| **Body Text**             | `Montserrat` (Sans-serif)  | Regular / Light             | 16px / 14px (Line-height: 1.6)        | Ref: Body Text description under headings       |
| **Buttons / Navigation**  | `Montserrat` (Sans-serif)  | Medium / SemiBold           | 13px / 12px (Letter-spacing: +0.05em) | Ref: "Explore Our Rooms", "Book Now"            |

### 1.3 UI Elements & Buttons

- **Primary Button (Filled):** พื้นหลัง Deep Brown (`#654433`) ตัวหนังสือสีขาวขุ่น ไม่มีขอบมน (Sharp corners หรือ Border-radius เล็กน้อย 2px)
  - _Ref: ตัวอย่างปุ่ม "Book Now" ใน UI ELEMENTS & ICONS_
- **Secondary Button (Outlined/Ghost):** พื้นโปร่งใส ขอบเส้นบางสี Deep Brown (`#654433`) หรือสีทราย
  - _Ref: ตัวอย่างปุ่ม "Learn More"_
- **Line Icons:** เส้นไอคอนสไตล์ Minimalist บางประณีต ได้แก่:
  - เตียงนอน (`Rooms`), ส้อมมีด (`Dining`), ใบไม้ (`Experiences`), หมุดแผนที่ (`Location`)
  - คลื่นทะเล (`Waves`), พระอาทิตย์ (`Sun`), ภูเขา (`Mountain`)

## 2. Page Structure & Wireframe Mapping

### Section 1: Top Navigation Bar

- **Ref:** ด้านบนสุดของ Hero ภาพซ้ายบน
- **องค์ประกอบ:**
  - ซ้าย: โลโก้เชิงสัญลักษณ์ลายเส้นภูเขา + ตัวอักษร `TERRALUME HOTEL & RESORT`
  - กลาง: เมนูลิงก์แนวนอน: `Home`, `Rooms`, `Experiences`, `Dining`, `Gallery`
  - ขวา: ปุ่มกดสี่เหลี่ยมผืนผ้า `Book Now`

### Section 2: Hero Section (Main Impression)

- **Ref:** ภาพหลักมุมมองจากวิลล่าสระว่ายน้ำพาโนรามา
- **องค์ประกอบ:**
  - Background: ภาพวิวทะเลระเบียงหินทรายและสระว่ายน้ำ
  - Text Layer (ฝั่งซ้าย):
    - Eyebrow: `A PLACE TO SLOW DOWN`
    - Main Title: `Nature's Beauty, Your Perfect Stay`
    - Paragraph: `Terralume Hotel & Resort offers a serene escape where natural beauty meets thoughtful comfort.`
    - CTA Button: `Explore Our Rooms`
  - Slider Indicators: ตัวเลข `01  02  03` บริเวณล่างซ้าย

### Section 3: Room Feature Spotlight (Deluxe Sea View Room)

- **Ref:** ตัวอย่างหน้าจอ `WEB PAGE EXAMPLES` (ภาพซ้ายล่าง)
- **องค์ประกอบ:**
  - รูปภาพห้องพักขนาดใหญ่ (ภาพเตียงนอนเปิดรับวิวทะเล)
  - รูปภาพส่วนระเบียงแนวตั้งเสริมด้านขวา
  - ข้อความชื่อห้อง: `Deluxe Sea View Room` (Playfair Display)
  - รายละเอียดสั้นๆ: `Wake up to breathtaking ocean views in a space designed for comfort and tranquility.`
  - Amenities Bar: ไอคอนพร้อมระบุ `King Bed` | `Ocean View` | `35 m²`
  - ปุ่ม CTA: `View Details`

### Section 4: Experiences Grid

- **Ref:** ตัวอย่างหน้าจอ `WEB PAGE EXAMPLES` (ภาพกลางล่าง)
- **องค์ประกอบ:**
  - Header: Eyebrow `EXPERIENCES` + Title `More Than a Stay`
  - Description: กิจกรรมโยคะ การรับประทานอาหารพื้นถิ่น
  - CTA Button: `Explore Experiences`
  - Photo Cards 3 คอลัมน์:
    1. **Wellness** (ภาพคนทำโยคะริมทะเล)
    2. **Local Culture** (ภาพการรับประทานอาหารพื้นเมืองร่วมกัน)
    3. **Adventure** (ภาพเรือล่องทะเลธรรมชาติ)

### Section 5: Mobile Screen Viewport

- **Ref:** ตัวอย่างหน้าจอมือถือ (ภาพขวาล่างใน Web Page Examples)
- **องค์ประกอบ:**
  - Header แบบย่อ: โลโก้ตรงกลาง + แฮมเบอร์เกอร์เมนู (`☰`) ด้านขวา
  - การจัดวางแบบ Single Column ตัวหนังสือขนาดพอดีสายตา พร้อมปุ่ม `Book Now` กว้างเต็มสัดส่วน
